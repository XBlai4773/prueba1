# Mini_Reto

Este es un proyecto de prueba para entregar en aules como evidencia de saber como funciona un archivo md

## Objetivos

1. Ver el funcionamiento de los md
2. Ver como crear un git por comandos
3. Saber la sintaxis de un md

## Instalación

```bash
git clone https://github.com/XBlai4773/prueba1.git
```
